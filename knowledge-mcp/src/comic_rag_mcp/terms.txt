# jieba 用户词典：一行一个词，可带 `词频` 与 `词性`（都可省）。
# 格式：词 [词频] [词性]
#
# 为什么要这份文件：jieba 的默认词典是通用语料训练的，不认识本项目的专有词。
# 不加这份词典时，「判重」会被切成「判/重」、「图床」被切成「图/床」，
# 反而比两字滑窗更差 —— 所以要上 jieba，就必须配这份词典。
#
# 维护约定：
#   1. 只收**确实会被用户问到的领域词**，不要收通用词（「数据库」「接口」默认词典已有）；
#   2. 词频给个偏高的整数（如 1000）能提高该词整体成词的概率；不确定就省略；
#   3. 新增模块/术语时一并补这里 —— 它属于「分词契约」，和 README 同级维护。
