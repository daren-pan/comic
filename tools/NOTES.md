# tools · 知识库（AI 维护）

> 本文件是 tools（一次性迁移 / 改结构脚本）的**踩坑与知识沉淀**，由 AI 协作时维护 ——
> **每次踩坑 / 实测 / 复盘写到这里**，不再写进 `README.md`（README 只放脚本清单与用途，给人看）。
> ⚠️ **脚本的回滚限制**（哪些不可逆、哪些会丢数据）集中在 README 的清单表 —— 那是"跑之前必须看"的；
> 本文件只放**跑完之后才知道的**（实测、复盘）。

## 条目模板（新增知识时按此写）

```markdown
#### 标题（一句话说清是什么）

- **日期**：YYYY-MM-DD（多个用 ` / ` 分隔）
- **背景 / 现象**：发生了什么（决策类写"当时的背景"）
- **根因**：为什么会这样（决策类写"为什么这么定"）
- **结论**：怎么解决 / 最终决定是什么
- **实测**（可选）：关键数字 / 验证方式
- **位置**（可选）：涉及的文件 / 页面
```
