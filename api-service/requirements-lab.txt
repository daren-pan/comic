#   上面这一套会拉进 80+ 个传递依赖（kubernetes、grpcio、onnxruntime、opentelemetry-sdk、

#
# 隔离是双向的：
#   · 依赖层 —— 本文件独立，deploy/api/Dockerfile 只装 requirements.txt；
#   · 代码层 —— routers/chat.py 里所有 langchain 相关 import 都在函数内部，
#     没装依赖时 api 正常启动，只有请求 `/api/chat/lab/*` 才返回 503；
#   · 开关层 —— COMIC_CHAT_LAB=0 时路由根本不挂载（404）。
#
# 也就是说：**忘了一件事也不会炸线上**。这是刻意的。
