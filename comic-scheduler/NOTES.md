## 一、任务与可观测性

### 1.1 ⚠️ 任务号必须带随机后缀（2026-10-06）

- **背景 / 现象**：定时器一轮接一轮，任务号若只用秒级时间戳，**同一秒内的第二轮**
  直接撞 `admin_task` 的唯一键。
- **根因**：实测 `Duplicate entry` —— 且第二轮的收尾会**覆盖第一轮的行**（比报错更糟：数据被串改）。
- **结论**：统一用 `comic_core.logctx.new_task_id`（**与 api 侧同一套规则**），任务号带随机后缀。
- **位置**：`src/comic_scheduler/daemon.py`。
